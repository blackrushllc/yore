Download the most recent builds here.

Select your OS and then choose the build which has the Mods you want. Not all combinations are available. To get a build with all the Mods, choose the "All" build. If you are having trouble downloading, try the "All" build. The smallest builds are the ones without any Mods, which contain only the core BASIC language interpreter and compiler. The largest builds are the ones with all the Mods, which contain core BASIC language interpreter and compiler plus all the Mods built in. For more info about Mods, see the Docs.
