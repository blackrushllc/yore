<h1>Yore Tutorial Script</h1>
<p>Well, this will eventually be a tutorial, right now it's just an outline :/</p>
<ol>
<li>Introduction - What is Yore?
<ol>
<li>The 8 fundamental Pillars of Yore
<ol>
<li>Yore is an MVC for building web applications</li>
<li>Yore has 2 View Template Engines
<ol>
<li>Standard HTML (Called "Fred")&nbsp;</li>
<li>"Blade" like in Laravel</li>
<li>(I might add Twig too)</li>
<li>You can use these interchangeably <strong>based on the file name of the template</strong></li>
</ol>
</li>
<li>Yore has a platform independent Controller &amp; Template Language (called "<strong>Fred</strong>")</li>
<li>Yore has automatic URI routing
<ol>
<li>In Modules:
<ol>
<li>Web Trait function names are website routes</li>
<li>API Trait controller function names are API routes</li>
<li>Also, <strong>Fred </strong>Trait function names automatically become Fred and Blade "@template()" functions</li>
</ol>
</li>
<li>Otherwise domain, site &amp; view folders automatically become routes</li>
<li>Multiple Views selected from a route can be based on the user's Role value</li>
</ol>
</li>
<li>Yore apps can be deployed anywhere you can store data
<ol>
<li>Disk files (Like you normally do)</li>
<li>Database</li>
<li>GitHub/GitLab, etc</li>
<li>FTP, DropBox, S3</li>
<li>(anywhere a URL can return JSON)</li>
</ol>
</li>
<li>Yore has a really useful Module Engine
<ol>
<li>For extending Yore in the platform/language of your choice (i.e. Php, Python)</li>
<li>Or modules can be built using Fred to be platform independent</li>
</ol>
</li>
<li>Yore apps can be interconnected
<ol>
<li>Instantiate and use an object on a different server</li>
<li>Distribute tasks to multiple servers</li>
</ol>
</li>
<li>Yore has built-in version control and deployment and unit testing tools</li>
</ol>
</li>
<li>Honerable Mention Pillars of Yore
<ol>
<li>A useful CLI:
<ol>
<li>Table CRUD Code and Page generator</li>
<li>Site cloning tool</li>
<li>Class Tinker tool</li>
<li>Push/Pull whole sites to/from data source</li>
<li>Excel integration tool</li>
<li>_________________</li>
</ol>
