<li>Introduction - What is Yore?
<ol>
<li>The 8 fundamental Pillars of Yore (still thinking about #8)
<ol>
<li>Yore is an MVC</li>
<li>Yore has 2 View Template Engines
<ol>
<li>Standard HTML (Called "Fred")&nbsp;
<ol>
<li>Back-end code in Fred templates are platform/language independent (i.e. does not require Php or Python specifically)</li>
</ol>
</li>
<li>"Blade" like in Laravel
<ol>
<li>Back-end code in the Blades must be in the language of the Framework (i.e. Php)</li>
<li>&nbsp;</li>
</ol>
</li>
<li>You can use these interchangeably based on the file name of the template</li>
<li>&nbsp;</li>
</ol>
</li>
<li>Yore has a platform independent Controller Programming Language ("Fred")</li>
<li>Yore apps can be deployed anywhere you can store data
<ol>
<li>Disk files (Like you normally do)</li>
<li>Database</li>
<li>GitHub/GitLab, etc</li>
<li>FTP, DropBox, S3</li>
<li>(anywhere a URL can return JSON)</li>
</ol>
</li>
<li>Yore has a really useful Module Engine
<ol>
<li>For extending Yore in the platform/language of your choice (i.e. Php, Python)</li>
<li>Or modules can be built using Fred to be platform independent</li>
</ol>
</li>
<li>Yore apps can be interconnected
<ol>
<li>Instantiate and use an object on a different server</li>
<li>Distribute tasks to multiple servers</li>
</ol>
</li>
<li>Yore has built-in version control and deployment tools</li>
